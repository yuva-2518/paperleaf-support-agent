# DemoKart demo data

DemoKart is a made-up online shop in India. Everything in this folder is invented. There is no real customer data anywhere.

| File | What it is | Used in |
|---|---|---|
| `demokart-faqs.csv` | 20 frequently asked questions with answers | The DemoKart FAQ Google Sheet (Session 2, Google Sheet track) |
| `help-docs/faqs.md` | The same 20 FAQs, as a help page | Session 2, help-docs track |
| `help-docs/returns-and-refunds-policy.md` | Returns and refunds policy | Session 2, help-docs track |
| `help-docs/shipping-and-delivery-policy.md` | Shipping and delivery policy | Session 2, help-docs track |
| `help-docs/warranty-and-repairs-policy.md` | Warranty and repairs policy | Session 2, help-docs track |

The DemoKart FAQ Google Sheet holds the same rows as `demokart-faqs.csv`. Anyone with the link can view it:
https://docs.google.com/spreadsheets/d/1UGMEwRtVSaZ2ZdiTl49NEAO5RudEsJnF1UdCuW0Oz_U/edit

If you are building your own business, you will use the Sheet or help docs from your brief instead.
